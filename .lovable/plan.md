

# 물류택배 양식 선택 다운로드 기능

## 개요
유료 회원 관리 페이지에서 체크박스로 원하는 회원만 선택하여 물류택배 양식(Excel)으로 다운로드할 수 있는 기능을 추가합니다.

---

## 주요 기능

### 1. 체크박스 선택 시스템
- 테이블 헤더에 전체 선택/해제 체크박스 추가
- 각 행에 개별 선택 체크박스 추가
- 선택된 항목 수 실시간 표시

### 2. 선택 항목 Excel 다운로드
- 선택된 회원만 물류택배 양식으로 추출
- CSV 대신 Excel(.xlsx) 형식 지원
- 기존 물류택배 버튼을 선택 기반으로 변경

---

## 구현 계획

### 파일 수정: `src/pages/PaidMembersAdmin.tsx`

**1. 상태 추가**
```typescript
const [selectedIds, setSelectedIds] = useState<Set<string>>(new Set());
```

**2. 선택 핸들러 함수**
- `handleSelectAll`: 현재 필터된 전체 선택/해제
- `handleSelectOne`: 개별 항목 선택/해제

**3. 테이블 UI 변경**
- 첫 번째 컬럼에 체크박스 추가
- 헤더에 전체 선택 체크박스

**4. Excel 다운로드 함수**
- SheetJS(xlsx) 라이브러리 사용
- 선택된 항목만 필터링하여 Excel 생성
- 물류택배 양식 포맷 유지

---

## 기술적 세부사항

### 의존성 추가
```bash
npm install xlsx
```
SheetJS는 클라이언트에서 Excel 파일을 생성할 수 있는 라이브러리입니다.

### UI 변경 사항

| 위치 | 변경 내용 |
|------|----------|
| 테이블 헤더 첫 컬럼 | 전체 선택 체크박스 |
| 테이블 각 행 첫 컬럼 | 개별 선택 체크박스 |
| 물류택배 버튼 | 선택된 개수 표시 및 비활성화 조건 |

### 버튼 동작 변경

**기존:**
```
물류택배 양식 (23명)  ← 필터된 전체 다운로드
```

**변경 후:**
```
물류택배 양식 (5명 선택)  ← 체크된 항목만 다운로드
```

선택된 항목이 없으면 버튼 비활성화

---

## 예상 결과

1. 관리자가 배송할 회원을 개별적으로 선택 가능
2. 선택한 회원만 Excel 파일로 추출
3. 물류택배 업체에 바로 업로드 가능한 양식 유지
